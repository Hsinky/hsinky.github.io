## 0.3.6（2026-09-16）
- [修复] 后缀插槽位次与文档承诺不符：readme 与样式注释均承诺「清除按钮出现/消失不会使后缀位移」，但原装配把后缀排在清除按钮之前、清除按钮最靠右——清除按钮 0↔24px 宽度翻转由 flex 输入区在右缘吸收，其左侧的计数/后缀/眼睛全部横移 24px，承诺从未成立。右侧动作区重排为 清除按钮 → 密码眼睛 → 字数统计 → 后缀插槽：宽度翻转仍由输入区吸收，但吸收点在清除按钮左缘，右侧常驻节点零位移，承诺成真；位次同时对齐主流规范（内容态清除图标贴文字，常驻动作与用户内容钉右端）
- [变更] 密码眼睛移到清除按钮之后（不再随首字符键入横移 24px）；字数统计移到动作图标之后（清除+计数同开时计数不再随空/非空跳位，单一配置下位次不变）
- [优化] 眼睛触控条几何与清除按钮真正对齐（16px 图标贴右 + 8px 间距，原为居中 4px/4px，与样式注释「几何与清除按钮一致」的声明不符），右侧全部节点统一 8px 间距节奏
